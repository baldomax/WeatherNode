# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue for security-sensitive bugs.
2. **Email** the maintainers (e.g. via the contact method listed in the repository or your preferred private channel) with a clear description of the issue, steps to reproduce, and impact.
3. Allow a reasonable time for a fix before disclosing publicly.

We will acknowledge your report and work with you to understand and address the issue.

## Security updates

Security-relevant fixes may be released as patch versions. Follow [CHANGELOG.md](CHANGELOG.md) and GitHub releases for announcements.
